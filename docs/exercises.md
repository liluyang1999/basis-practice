# 语法练习索引

入口均为 `grammar.nowcoder.Java编号`。`tests/GrammarTest.java` 有每一道题的完整输入和预期输出，并在独立 JVM 中验证，避免 System.in 关闭、静态状态、默认时区和区域设置干扰其他题。

这些是有明确输入约束的练习，不把每题改成通用输入校验框架。除下面列出的扩展边界外，缺少必填 token、类型错误或越界输入可以异常退出。原题中的 `int` 算术仍使用 Java 规则，不承诺所有数值组合都避免溢出。

Java32 原仓库缺失。Java6 的分类和 Java46 的历史税率仅服务于语法练习；没有将这些内容更新成健康或税务计算产品。

Java23 示例：输入 `grammar.nowcoder.Java23First`。Java24 示例：输入 `grammar.nowcoder.Java24Sub1`。反射只允许本题列出的类型，用 `getDeclaredConstructor().newInstance()` 替代弃用 API，不接受任意外部类名。

Java36 的输出遵循时区规则；2024-01-01 12:00:00 上海对应纽约前一天 23:00:00，2024-07-01 12:00:00 上海对应纽约同日 00:00:00。不能用固定减 12 小时替代时区转换。JDK 的时区数据库版本会影响未来规则变更的结果。

学习方法：先运行正常样例，再尝试边界，并区分“题目输入不满足契约”和“算法对契约内数据算错”。已有测试包含空正数序列、零/负数位数、LCM 溢出、Unicode、整数极值比较、闰年和冬夏时区。
