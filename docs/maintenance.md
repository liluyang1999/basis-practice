# 维护记录与验证边界

基线提交：`383432a5cb10aa00faf9e1495e8473485225fae8`。本次不引入第三方依赖，保留 Java 19 目标及原项目结构。

## 从复现到修复

`RegressionTest` 在原始类文件上复现 12/12 失败：选择排序自交换、长度 2 的 ShellSort、未实现的 Heap/Radix、Counting/Bucket 空输入、旧堆排序/希尔排序、泛型插入、二分插入、左式堆空实现、1 被判为素数。

独立进程语法用例进一步复现输出格式异常、EOF 崩溃、LCM 除零、零次反弹负路程、空均值 NaN、零/负数位数、带符号千分位、负整数二进制、冬季纽约时差、日期宽松解析、代理对破坏和比较器溢出。首次测试中的固定二维数组总和预期值也经手工重算修正为 5180，测试预期不是免审证据。

未完成的工厂方法、抽象工厂、命令和责任链示例现在有角色、可执行 main 和行为测试。配对堆消除原始类型，公开有归属校验的句柄，删除最小值完整解除链接；Treap 修复未保存构造参数及旋转不能返回新根。

## 兼容变化

- `TestUtil` 现在返回/接收副本；调用者须排序自己持有的数组。
- `PairingHeap.insert` 返回插入句柄；`merge(Node)` 拒绝仍属于别的堆的节点。
- `LeftIsHeap` 从空实现变为真正最小堆；空堆读取/删除抛异常。
- Treap 旋转返回新根，需要调用者接回；现有编译后的调用方应重新编译。
- `AjaxResult` 保留 code=1/0 的业务示例语义，声明 final，避免构造过程中调用可覆盖的 Map 行为。
- Java36 遵循真实时区，Java38/43/47 输出顺序固定；Java23/24 反射增加类型白名单。
- 文件 I/O 必须提供路径，取消固定盘符写入；重复写入失败。

## 检查入口

`./scripts/build.ps1 -Test` 包含源码/测试编译、全部警告视为失败、固定时间戳 JAR 打包、数组与堆性质测试、50 道题及错误路径的 CLI 验证、实际 JAR 示例启动、NIO 真实文件与资源测试、单例并发测试、模式状态与树结构测试。

`AlgorithmsTest`：9,530 个断言。`RegressionTest`：12 个复现用例。`GrammarTest`：73 个独立进程检查，覆盖全部 50 题。`ExamplesTest`：33 个打包后 CLI 检查。其余测试覆盖 UTF-8、资源关闭、旋转、结构和模式状态。数字按当前测试源码计，不代表代码覆盖率百分比。

没有第三方格式器、空值分析器、覆盖率或基准测试工具；未安装这些工具。静态检查由 JDK `-Xlint:all -Werror` 加人工审查完成；测试对有意与示例同文件的包级角色只局部抑制 `auxiliaryclass` 提示。没有添加自动下载 JDK 的 CI 工作流。实际运行范围是当前 Windows/JDK 25.0.2；其他平台和 JDK 19 运行时需要另行执行同一门禁。

JAR 内容可在固定 JDK 下复现；编译器版本会影响字节码，所以跨 JDK 不承诺相同哈希。没有引入持续运行服务、测试端口或需要清理的外部数据。
